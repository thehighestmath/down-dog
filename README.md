============================================================
ДОКУМЕНТАЦИЯ ПО DOCKER (MINIO S3-ХРАНИЛИЩЕ)
============================================================

В этом проекте для хранения изображений используется MinIO — 
S3-совместимое объектное хранилище, запускаемое в Docker-контейнере.

============================================================
1. УСТАНОВКА DOCKER
============================================================

Если Docker ещё не установлен:

1. Скачайте Docker Desktop с официального сайта:
   https://www.docker.com/products/docker-desktop/

2. Установите, следуя инструкциям установщика.

3. Запустите Docker Desktop (значок кита в системном трее должен стать зелёным/активным).

4. Убедитесь, что используется WSL 2 (рекомендуется) – обычно это настройка по умолчанию.

============================================================
2. ПЕРВЫЙ ЗАПУСК MINIO (СОЗДАНИЕ КОНТЕЙНЕРА)
============================================================

Выполняется ТОЛЬКО ОДИН РАЗ – при первой настройке проекта.

Откройте терминал (PowerShell, cmd или WSL) и выполните команду:

docker run -d --name minio -p 9000:9000 -p 9001:9001 -e "MINIO_ROOT_USER=minioadmin" -e "MINIO_ROOT_PASSWORD=minioadmin" -v minio_data:/data minio/minio server /data --console-address ":9001"

Параметры:
  -d                          Запуск в фоновом режиме.
  --name minio                Имя контейнера.
  -p 9000:9000                Порт для S3 API.
  -p 9001:9001                Порт для веб-консоли.
  -e "MINIO_ROOT_USER=..."    Логин для доступа (по умолчанию minioadmin).
  -e "MINIO_ROOT_PASSWORD=.." Пароль для доступа (по умолчанию minioadmin).
  -v minio_data:/data         Создание тома Docker для хранения данных (файлы сохраняются).

После запуска:
- Проверьте, что контейнер работает:
  docker ps
  (должен быть список с контейнером minio со статусом Up)

- Откройте веб-консоль в браузере: http://localhost:9001
- Войдите с логином minioadmin и паролем minioadmin.
- Создайте бакет (bucket) – например, yogaimages (без дефисов).
- (Опционально) Сделайте бакет публичным: выберите бакет → Access Policy → Public.

============================================================
3. ПОСЛЕДУЮЩИЕ ЗАПУСКИ (КОГДА КОНТЕЙНЕР УЖЕ СОЗДАН)
============================================================

После перезагрузки компьютера или остановки Docker контейнер не запускается автоматически.
Чтобы продолжить работу с MinIO, выполните шаги:

3.1 Проверьте статус контейнера:
    docker ps -a | findstr minio
    (для Linux/macOS используйте grep вместо findstr)

    - Если статус Up – контейнер уже работает, переходите к п. 3.4.
    - Если статус Exited или Created – контейнер остановлен, его нужно запустить.

3.2 Запустите существующий контейнер:
    docker start minio

3.3 Проверьте, что он запустился:
    docker ps
    (должен быть статус Up)

3.4 Откройте веб-консоль:
    http://localhost:9001
    (данные сохранились, бакеты и файлы на месте)

3.5 В Python-скрипте используйте те же настройки подключения (из .env):
    endpoint_url = http://localhost:9000
    access_key = minioadmin
    secret_key = minioadmin
    bucket_name = yogaimages (или то, что вы создали)


============================================================
4. ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ (.env)
============================================================

Для подключения к MinIO из Python используйте файл .env в корне проекта:

MINIO_ENDPOINT=http://localhost:9000
ACCESS_KEY=minioadmin
SECRET_KEY=minioadmin
BUCKET_NAME=yogaimages

ВАЖНО: .env НЕ ДОЛЖЕН ПОПАДАТЬ В GIT. Добавьте его в .gitignore.
В репозитории должен лежать файл-пример .env.example с теми же переменными.
