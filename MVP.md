# MVP: Yoga Training App — Ядро тренировки

> **Принцип:** Минимум кода, максимум проверки гипотезы. Без регистрации, без админки, без истории.

---

## 1. Цель MVP

Проверить гипотезу: **нужен ли пользователям сервис персонализированных йога-тренировок с AI-подбором и озвучкой.**

**Критерии успеха:**
- Пользователь может создать тренировку за < 30 секунд
- Тренировка проходит без технических сбоев
- Пользователь возвращается хотя бы 1 раз

## 5. Модель данных (MVP)

### Таблица: `poses`

```sql
CREATE TABLE poses (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name_ru         VARCHAR(100) NOT NULL,        -- "Поза собаки мордой вниз"
    name_sanskrit   VARCHAR(100),                 -- "Адхо Мукха Шванасана"
    name_en         VARCHAR(100),                 -- "Downward-Facing Dog"
    
    category        VARCHAR(50) NOT NULL,         -- standing, sitting, balancing, inversion, relaxation
    difficulty      INTEGER NOT NULL CHECK (difficulty BETWEEN 1 AND 5),
    
    focus_areas     TEXT[],                       -- ["back", "legs", "shoulders"]
    contraindications TEXT[],                     -- ["wrist_injury", "high_blood_pressure"]
    
    description     TEXT,                         -- текстовое описание техники
    image_url       TEXT NOT NULL,                -- S3 URL
    audio_url       TEXT,                         -- S3 URL с TTS (генерируется по требованию)
    
    created_at      TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_poses_category ON poses(category);
CREATE INDEX idx_poses_difficulty ON poses(difficulty);
CREATE INDEX idx_poses_focus ON poses USING GIN(focus_areas);
```

### Seed-данные (30-50 поз)

| Категория | Примеры поз |
|-----------|-------------|
| **Разминка** (warmup) | Поза ребёнка, Кошка-корова, Наклон вперёд сидя |
| **Стоя** (standing) | Поза горы, Воин I, Воин II, Поза дерева |
| **Сидя** (sitting) | Поза лотоса, Наклон вперёд, Скрутка сидя |
| **Балансы** (balancing) | Поза дерева, Поза орла |
| **Заминка** (relaxation) | Шавасана, Поза счастливого ребёнка |

## 6. API (MVP)

### GET /api/poses

Получить каталог поз (опционально с фильтрами).

**Query params:**
- `category` — фильтр по категории
- `difficulty` — максимум сложность (1-5)
- `focus` — фокус_area

**Response:**
```json
[
  {
    "id": "uuid",
    "name_ru": "Поза собаки мордой вниз",
    "name_sanskrit": "Адхо Мукха Шванасана",
    "category": "standing",
    "difficulty": 2,
    "focus_areas": ["back", "legs"],
    "image_url": "https://s3/...",
    "description": "..."
  }
]
```

### POST /api/workouts/generate

Сгенерировать тренировку.

**Request:**
```json
{
  "duration_min": 15,
  "level": "beginner",
  "focus": "back"
}
```

**Response:**
```json
{
  "workout_id": "uuid",
  "duration_sec": 900,
  "poses": [
    {
      "pose_id": "uuid",
      "name": "Поза ребёнка",
      "image_url": "https://s3/...",
      "audio_url": "https://s3/...",
      "hold_seconds": 30,
      "transition_seconds": 5,
      "phase": "warmup"
    }
  ]
}
```

### GET /api/workouts/:id

Получить сгенерированную тренировку (если нужно дозагрузить).

## 7. Логика генератора (Rule-based)

```python
def generate_workout(duration_min: int, level: str, focus: str):
    # 1. Маппинг уровня в максимальную сложность
    max_difficulty = {"beginner": 2, "intermediate": 3, "advanced": 5}[level]
    
    # 2. Фильтрация поз
    candidate_poses = poses.where(
        difficulty <= max_difficulty
        and focus in focus_areas
        and category not in ["inversion"] if level == "beginner"
    )
    
    # 3. Расчёт количества поз
    avg_hold = 30  # секунд
    transition = 5
    total_poses = (duration_min * 60) / (avg_hold + transition)
    
    # 4. Распределение по фазам
    warmup_count = int(total_poses * 0.2)
    main_count = int(total_poses * 0.6)
    cooldown_count = total_poses - warmup_count - main_count
    
    # 5. Подбор поз по фазам
    warmup_poses = candidate_poses.where(category in ["warmup", "sitting"]).limit(warmup_count)
    main_poses = candidate_poses.where(category in ["standing", "balancing"]).limit(main_count)
    cooldown_poses = candidate_poses.where(category in ["relaxation"]).limit(cooldown_count)
    
    # 6. Сборка тренировки
    workout = {
        "poses": [
            {"phase": "warmup", **pose} for pose in warmup_poses
        ] + [
            {"phase": "main", **pose} for pose in main_poses
        ] + [
            {"phase": "cooldown", **pose} for pose in cooldown_poses
        ]
    }
    
    return workout
```

## 8. TTS-озвучка

### Шаблоны инструкций

```python
TTS_TEMPLATES = {
    "intro": "Начинаем тренировку. Первая поза — {pose_name}.",
    "pose_enter": "Входим в позу {pose_name}.",
    "breathing": "Сделайте глубокий вдох... и медленный выдох.",
    "hold": "Держите позу... ещё {seconds} секунд.",
    "transition": "Плавно выходим. Переход к следующей позе.",
    "outro": "Тренировка завершена. Отдохните в Шавасане."
}
```

### Кэширование

- Ключ кэша: `hash(pose_id + template + language)`
- Хранилище: S3 + Redis (опционально)
- TTL: 30 дней

## 11. Риски MVP

| Риск | Вероятность | Mitigation |
|------|-------------|------------|
| Нет изображений поз | Medium | Использовать yoga-api (open source) |
| TTS дорогой | Medium | Кэшировать 100%, использовать Yandex |
| Генератор выдаёт ерунду | High | Ручная проверка первых 10 тренировок, adjustment правил |
| Таймер глючит на мобильных | Medium | Использовать `requestAnimationFrame`, тест на реальных устройствах |
